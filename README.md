# 风控建模助手 Risk Modeling Assistant

> 让信贷风控团队用自然语言完成建模前后的资料查询、特征理解与策略复盘。

## 解决什么问题

信贷风控团队的日常工作高度依赖规则与模型的上下文知识：准入规则散落在多版策略文档里、特征字典更新频繁、模型上线与迭代记录缺乏统一入口。业务和策略同事经常要花大量时间翻文档、问同事、对口径。

风控建模助手把规则库、特征字典、模型迭代记录做成可对话的知识底座，用一句话就能完成：

- "新客首贷当前的准入规则有哪些？"
- "这个特征最近一次口径调整是什么时候，为什么调？"
- "对比 A/B 两版策略的准入差异"

## 功能规划（Roadmap）

- [ ] v0.1 风控规则知识库 + 自然语言检索（RAG）
- [ ] v0.2 特征字典查询与口径解释
- [ ] v0.3 策略版本对比与影响分析
- [ ] v0.4 模型迭代时间线复盘
- [ ] v1.0 Web 界面 + 多用户场景支持

## 技术架构（初版规划）

- LLM：DeepSeek / GPT-4o / Claude
- 检索：向量数据库 + RAG 管道（文档解析、切分、embedding、召回）
- Agent 工作流：意图识别 → 检索 → 归纳回答（含引用出处）
- 前端：微信小程序 / Web Demo
